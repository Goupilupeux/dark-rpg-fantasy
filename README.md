# 🎲 Dark Fantasy RPG - MJ IA Solo

JdR solo immersif avec IA (Poe + Claude 3.5 Sonnet) et voix française (ElevenLabs).

## 🚀 Déploiement sur Render

1. Crée un compte sur render.com
2. Clique "New +" → "Web Service"
3. Connecte ce repo GitHub
4. Configure:
   - Build Command: `npm install`
   - Start Command: `node index.js`
5. Ajoute les variables d'environnement:
   - `POE_API_KEY` = ta clé Poe
   - `ELEVENLABS_API_KEY` = ta clé ElevenLabs
   - `PORT` = 3001
6. Deploy!

## 🎮 Utilisation

- Ouvre l'URL Render dans ton navigateur
- Dicte ou tape tes actions en français
- Le MJ répond avec voix française réaliste
- Univers: Dark Fantasy (Berserk/Witcher)

## 🔑 Clés API nécessaires

- **Poe API**: poe.com/account/profile
- **ElevenLabs**: elevenlabs.io/account/settings/api-keys
